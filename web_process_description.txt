Процесс загрузки сайта при вводе URL в браузере

1. DNS-запрос
Браузер отправляет запрос к DNS серверу чтобы получить IP адрес по доменному имени (например, example.com -> 93.184.216.34)

Примерное время ~20–100 мс

Возможные проблемы:
- DNS-сервер недоступен
- Неправильная запись домена
- Медленный DNS

2. Установка TCP-соединения
Браузер устанавливает TCP соединение с сервером (SYN -Ю SYN-ACK -> ACK)

Примерное время ~50–200 мс

Возможные проблемы:
- Высокая задержка сети
- Блокировка портов
- Сервер не отвечает

3. HTTP запрос
Браузер отправляет HTTP запрос (GET /index.html) с заголовками (User-Agent, Cookies и др.)

Примерное время ~10–50 мс

Возможные проблемы:
- Неправильный запрос
- Большие заголовки
- Проблемы с сетью

4. Обработка на сервере
Сервер принимает запрос, обрабатывает его (логика приложения, работа с БД, формирование ответа)

Примерное время ~50–500 мс

Возможные проблемы:
- Медленные SQL запросы
- Ошибки в коде (500)
- Перегрузка сервера

5. HTTP ответ
Сервер отправляет ответ (HTML, JSON и т.д.) со статусом (200, 404, 500)

Примерное время ~10–100 мс

Возможные проблемы:
- Большой размер ответа
- Потери пакетов
- Ошибки сервера

6. Рендеринг в браузере
Браузер парсит HTML, загружает CSS/JS, строит DOM и отображает страницу

Примерное время ~100–1000 мс

Возможные проблемы:
- Тяжёлые скрипты
- Большие изображения
- Блокирующий CSS/JS
