Диагностика проблем загрузки сайта

1. DNS запрос

Инструменты:
- nslookup
- dig

Как проверить:
- nslookup example.com
- dig example.com

Проблемы:
- DNS не отвечает
- Неверный IP
- Медленный ответ

Решение:
- Проверить DNS-сервер (например, 8.8.8.8)
- Очистить кэш DNS (ipconfig /flushdns)
- Проверить записи домена

2. TCP соединение
Инструменты:
- ping
- telnet

Как проверить:
- ping example.com
- telnet example.com 80

Проблемы:
- Высокая задержка
- Потеря пакетов
- Порт закрыт

Решение:
- Проверить сеть
- Открыть порт на сервере
- Проверить firewall

3. HTTP запрос
Инструменты:
- curl
- DevTools (Chrome/Firefox)

Как проверить:
- curl -I http://example.com
- вкладка Network в DevTools

Проблемы:
- Неверный URL
- Ошибки заголовков
- CORS

Решение:
- Проверить endpoint
- Проверить headers
- Настроить CORS

4. Обработка на сервере
Инструменты:
- Логи
- Время ответа

Как проверить:
- Посмотреть логи сервера
- Проверить время ответа

Проблемы:
- Медленные SQL запросы
- Ошибки 500
- Перегрузка сервера

Решение:
- Оптимизировать запросы
- Проверить код
- Масштабировать сервер

5. HTTP ответ
Инструменты:
- curl

Как проверить:
- Статус ответа (200, 404, 500)
- Размер ответа

Проблемы:
- Большой размер ответа
- Ошибки сервера
- Неправильный статус

Решение:
- Сжать данные (gzip)
- Исправить ошибки
- Настроить кэширование

6. Рендеринг в браузере
Инструменты:
- Chrome DevTools
- Lighthouse

Как проверить:
- Вкладки Performance и Lighthouse

Проблемы:
- Медленный JS
- Большие изображения
- Блокирующий CSS

Решение:
- Минификация JS/CSS
- Ленивая загрузка
- Оптимизация изображений
