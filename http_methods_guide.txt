HTTP методы и статусы для проекта SFMShop

1. Получение списка товаров
Метод: GET
Путь: /products
Статус: 200 OK

Пример запроса:
GET /products

Пример ответа:
200 OK
[
  {"id": 1, "name": "Laptop", "price": 1200, "quantity": 10},
  {"id": 2, "name": "Phone", "price": 800, "quantity": 20}
]
------------------------------------------------------------------
2. Получение товара по id
Метод: GET
Путь: /products/{id}
Статус: 200 OK / 404 Not Found

Пример запроса:
GET /products/1

Пример ответа:
200 OK
{"id": 1, "name": "Laptop", "price": 1200, "quantity": 10}
или
404 Not Found
{"detail": "Product not found"}
------------------------------------------------------------------
3. Создание нового заказа
Метод: POST
Путь: /orders
Статус: 201 Created

Пример запроса:
POST /orders
{
  "user_id": 1,
  "items": [
    {"product_id": 1, "quantity": 1},
    {"product_id": 2, "quantity": 2}
  ]
}

Пример ответа:
201 Created
{"order_id": 10, "message": "Order created successfully"}
------------------------------------------------------------------
4. Обновление данных товара
Метод: PUT
Путь: /products/{id}
Статус: 200 OK / 404 Not Found

Пример запроса:
PUT /products/1
{
  "name": "Laptop Pro",
  "price": 1500,
  "quantity": 5
}

Пример ответа:
200 OK
{"message": "Product updated successfully"}
или
404 Not Found
{"detail": "Product not found"}
------------------------------------------------------------------
5. Удаление товара
Метод: DELETE
Путь: /products/{id}
Статус: 200 OK / 204 No Content / 404 Not Found

Пример запроса:
DELETE /products/1

Пример ответа:
204 No Content
или
404 Not Found
{"detail": "Product not found"}
------------------------------------------------------------------
6. Получение заказов пользователя
Метод: GET
Путь: /users/{id}/orders
Статус: 200 OK

Пример запроса:
GET /users/1/orders

Пример ответа:
200 OK
[
  {"order_id": 1, "total": 1350, "created_at": "2026-01-01"},
  {"order_id": 2, "total": 950, "created_at": "2026-01-02"}
]
